# SatelliteOrbitSimulator

一個使用 C# Windows Forms 開發的 **2D 人造衛星軌道模擬器**，用於模擬衛星繞地球運動，並觀察衛星的位置、速度及軌道變化。

本專案以基礎軌道力學為核心，結合即時動畫與物理數據顯示，作為學習衛星軌道及數值模擬的練習專案。

## 專案目標

- 模擬人造衛星繞地球運動的過程。
- 觀察衛星軌道、位置與速度的變化。
- 比較模擬結果與理論軌道參數。
- 透過不同視圖觀察衛星運動。

## 使用技術

- **程式語言：** C#
- **開發平台：** Windows Forms
- **IDE：** Visual Studio
- **物理模型：** 牛頓萬有引力
- **數值積分方法：** 四階 Runge-Kutta（RK4）
- **繪圖方式：** System.Drawing

## 主要功能

### 軌道模擬
- 設定衛星初始高度、速度及角度。
- 計算衛星在地球引力作用下的運動。
- 使用 RK4 方法更新衛星的位置與速度。
- 偵測衛星是否進入地球範圍。

### 模擬控制
- 開始模擬。
- 暫停模擬。
- 重設模擬。
- 調整模擬時間倍率。

### 軌道視覺化
- **太空視圖：** 以太空場景呈現地球、衛星及運行軌跡。
- **座標視圖：** 以二維座標系統觀察衛星位置與軌道。
- 隨模擬進行記錄衛星軌跡。
- 視窗尺寸改變時重新繪製模擬畫面。

### 物理數據
- 顯示衛星目前高度。
- 顯示衛星目前速度。
- 顯示衛星與地心的距離。
- 顯示模擬經過時間。
- 顯示理論圓形軌道速度與週期。

## 執行方式

1. 下載或 Clone 本專案。
2. 使用 Visual Studio 開啟 `SatelliteOrbitSimulator.sln`。
3. 等待必要的專案相依性載入完成。
4. 建置方案。
5. 執行程式。

> 執行環境與 .NET 版本請以專案檔中的實際設定為準。

## 專案狀態

目前版本已建立基本的衛星軌道模擬、軌跡繪製、視圖切換及物理數據顯示功能。

後續將視實際需求，逐步擴充模擬與物理分析功能。
